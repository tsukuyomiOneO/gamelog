# Журнал изменений GameLOG

Стенды: тест работает только локально (`APP_ENV=staging node build.mjs`), в прод уходит версия из ветки `main` (Vercel собирает сам). Каждая правка записывается сюда: сначала в раздел «Не выпущено», при выходе в прод переносится под номер версии с датой.

## Не выпущено

### Beta v2.3
- Новый дизайн: тема «Аркада» (игровые автоматы США 2000-х) по умолчанию: неоновый логотип, бегущие лампочки на окнах, хром и золото, скан-линии.
- Анимации: барабаны для цифр в шапке, табло «LEVEL UP!», золотая плашка достижений, блеск на пройденных играх, «INSERT COIN» на пустом экране, корона лидера.
- Кнопка темы переключает Аркада → Светлая → Тёмная; галочка «Анимации и свечение» в аккаунте; учитывается системное «уменьшить движение».
- Откат: старые темы остались, при необходимости можно вернуть тег `v2.2`.

### Beta v2.2
- Сравнение с другом: общие игры, оценки, часы, чего нет у тебя или у друга.
- Посоветовать игру другу с коротким сообщением; друг добавляет её в «Хочу» одним нажатием или скрывает.
- Реакции на игры друга («Огонь», «Тоже хочу», «Пройди!»); владелец видит счётчики на своих карточках.
- В коллекции друга кнопка «В «Хочу»».
- Таблица лидеров среди друзей по XP (закрытые коллекции показываются без цифр).
- Миграция: `supabase/migrations/20261016000002_social_v22.sql`.

### Beta v2.1
- Профиль: 12 пиксельных аватаров, «О себе» и любимая игра. Видны друзьям в списке и в шапке чужой коллекции.
- Исправлено: игры друга могли появиться в твоей коллекции (свой запрос не фильтровал по владельцу).
- Миграция: `supabase/migrations/20261016000001_profile_fields.sql`.

### Beta v2.0
- Достижения: 17 штук, всплывающее уведомление при получении.
- Уникальные ники (без учёта регистра), меняются в аккаунте; новым аккаунтам выдаётся Player######.
- Друзья: поиск по нику, заявки, принять/отклонить/убрать.
- Просмотр коллекции друга (только чтение); переключатель «Друзья видят мою коллекцию».
- Бейдж версии. Миграция: `supabase/migrations/20261014000003_profiles_friends.sql`.

## 1.0.0 — 2026-10-13

Первый выпуск в прод.

- Название продукта: GameLOG.
- Мобильная версия повторяет дизайн ПК: шапка в одну строку, 4 колонки статистики, вкладки в 2 ряда, поля 16px (iOS не зумит), без горизонтального скролла от 320 px.
- Светлая тема по умолчанию на всех устройствах, кнопка переключения на тёмную в шапке, выбор запоминается.
- Подтверждение почты: понятное сообщение при использованной или устаревшей ссылке, кнопка «Отправить письмо ещё раз», определение уже существующей почты, сообщение о лимите отправки с таймером, приветствие после подтверждения.
- Сборка из переменных окружения (`build.mjs`), конфиг для Vercel (`vercel.json`) с заголовками безопасности.
- База: RLS, лимит 500 игр, обложки JPEG до 500 КБ, удаление аккаунта (`supabase/`).
